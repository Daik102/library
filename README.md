<h1>Project: Library</h1>
A library app with several features.
<br>
This project is based on <a href="https://www.theodinproject.com/">The Odin Project</a>.

<h3>Features</h3>

- Object-Oriented data model using ES6 class

- Add, edit, sort, search, and delete books seamlessly

- Constraint validation API

- Responsive Design implemented

<h3>Tech Stack</h3>

- Frontend: HTML CSS JavaScript

- Icons: <a href="https://pictogrammers.com/">Pictogrammers</a>
